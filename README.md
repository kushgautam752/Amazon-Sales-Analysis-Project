# 📦 Amazon Sales Analysis (2019–2024)

## 📌 Project Overview
This project analyzes **Amazon sales data from 2019 to 2024** to identify revenue trends, product performance, customer preferences, and seasonal patterns.  
Using **Excel** for cleaning and **Tableau** for visualization, we built an interactive dashboard to uncover actionable business insights.

## 📂 Files in Repository
- **`amazon_sales_dataset_2019_2024_corrected.xlsx`** – Raw dataset with sales, categories, and transaction details.
- **`Amazon Sales Analysis.twb`** – Tableau workbook containing the interactive dashboard.
- **`README.md`** – Documentation of the project.

## 🛠 Tools & Technologies
- **Excel** – Data cleaning & preprocessing
- **Tableau** – Data visualization & dashboard creation
- **Data Modeling** – Structured dataset for accurate insights

## 📊 Dashboard Features
- **Total Revenue & Orders** (Yearly, Quarterly, Monthly)
- **Top-Selling Products & Categories**
- **Geographical Sales Distribution**
- **Seasonal & Festive Sales Trends**
- **Customer Segment Analysis**

## 🔍 Key Insights
1. **Revenue Growth** – Highest revenue was recorded in 2023 due to festive sales.
2. **Best Performing Category** – Electronics contributed to over 35% of total revenue.
3. **Top Selling Month** – November saw the highest spike due to Black Friday & festive season.
4. **Customer Trends** – Repeat customers make up a significant share of high-value orders.
